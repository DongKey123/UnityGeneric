# 빌딩 UI 디자인 요청서

---

## 요청 개요

빌딩 관련 UI는 목적이 완전히 다른 두 화면으로 구성됩니다.

| 화면 | 형태 | 설명 |
|------|------|------|
| **건물 관리 패널** | 1760×1020 팝업 | 건물 제작 대기 목록 + 설치된 건물 목록 + 상세/수정 |
| **배치 모드 오버레이** | 소형 고정 오버레이 | 건물을 맵에 직접 놓는 중에만 표시되는 별개 화면 |

두 화면은 동시에 표시되지 않으며, 디자인 톤·형태가 다릅니다.  
각각 별도 HTML 시안으로 제작해 주세요.

# 화면 1 — 건물 관리 패널

## 규격 및 스타일

| 항목 | 값 |
|------|----|
| 기준 해상도 | 1920 × 1080 (가로) |
| 패널 크기 | **1760 × 1020** (중앙 배치) |
| 분위기 | 크래프팅 패널과 동일 패키지 — 다크 서바이벌 톤 |
| 팝업 크롬 | 크래프팅 패널과 동일 구조 요청 (타이틀바 + 푸터 포함) |

## 좌측 열 — 건물 목록

### 섹션 헤더

두 섹션으로 구분됩니다.

| 섹션 | 텍스트 예시 | 설명 |
|------|------------|------|
| 배치 대기 | `배치 대기  3` | 건설은 완료했지만 아직 맵에 놓지 않은 건물 |
| 설치됨 | `설치됨  5` | 맵에 배치 완료된 건물 |

각 헤더 우측에 해당 섹션 건물 수 표시.

---

### 건물 카드 — 배치 대기 (Pending)

카드 구성 요소:

| 위치 | 요소 | 설명 |
|------|------|------|
| 좌측 | 아이콘 슬롯 | 건물 아이콘 (약 72×72) |
| 중앙 상단 | 건물 이름 | 텍스트 |
| 중앙 하단 | 그리드 크기 | 예: `1 × 1`, `2 × 1` |
| 우측 | 상태 배지 | `대기 중` 라벨 (중립 색상) |

카드 상태: 기본 / 선택됨 (테두리 강조) 2종

---

### 건물 카드 — 설치됨 (Placed)

카드 구성 요소:

| 위치 | 요소 | 설명 |
|------|------|------|
| 좌측 | 아이콘 슬롯 | 건물 아이콘 (약 72×72) |
| 아이콘 위 | 체크 배지 | `✓ 설치됨` 배지 (녹색 계열) |
| 중앙 상단 | 건물 이름 | 텍스트 |
| 중앙 하단 | 그리드 크기 + 설치 위치 | 예: `1 × 1  ·  (3, 2)` |
| 우측 | 상태 배지 | `설치됨` 라벨 (녹색 계열) |

카드 상태: 기본 / 선택됨 (테두리 강조) 2종

## 우측 열 — 상세 / 수정 뷰

### A. 미선택 상태

우측 전체에 "건물을 선택하세요" 힌트 텍스트. 버튼 없음.

---

### B. 배치 대기 선택 시

| 구성 요소 | 설명 |
|-----------|------|
| 건물 아이콘 (대형) | 약 120×120 |
| 건물 이름 | 큰 폰트 |
| 카테고리 태그 | `구조물` / `가구` / `생산` |
| 그리드 크기 표시 | `1 × 1` 등 |
| 건설 비용 재료 행 | 이미 소모된 재료 목록 (흐리게 처리, 참고용) |
| 하단 버튼 2개 | `배치하기` (주 버튼, 초록) + `버리기` (보조 버튼, 빨강 계열) |

`버리기` 버튼 아래 작은 텍스트: "재료 일부를 돌려받습니다"

---

### C. 설치됨 선택 시

| 구성 요소 | 설명 |
|-----------|------|
| 건물 아이콘 (대형) | 약 120×120, 위에 `✓` 오버레이 |
| 건물 이름 | 큰 폰트 |
| 카테고리 태그 | `구조물` / `가구` / `생산` |
| 설치 위치 | 그리드 좌표 표시, 예: `위치 (3, 2)` |
| 내구도 바 | `내구도  72 / 100` 바 형태 |
| 하단 버튼 3개 | `이동` (보조) + `수리` (보조, 내구도 미달 시 활성) + `철거` (경고 계열) |

`철거` 버튼 아래 작은 텍스트: "재료 50%를 돌려받습니다"

## 주의사항 — 건물 관리 패널

1. **두 섹션이 하나의 스크롤 목록 안에 들어갑니다.** 배치 대기가 위, 설치됨이 아래. 섹션이 비어 있으면 해당 헤더도 숨깁니다.
2. **설치됨 카드는 선택 후 맵을 보여줘야 하는 상황이 생깁니다.** 이동/철거 액션 시 패널이 닫히고 배치 모드로 전환되므로, 카드 상태가 잠시 비는 케이스를 고려하지 않아도 됩니다 (코드 처리).
3. **내구도 바는 설치됨 상세에서만 표시됩니다.** 배치 대기 상태에는 내구도 표시 없음.
4. **`수리` 버튼은 내구도 100%일 때 비활성 처리됩니다.** 활성/비활성 2종 디자인 필요.
5. **좌측 목록이 비어있을 경우 (전체)** "건설한 건물이 없습니다" 힌트를 목록 중앙에 표시.

# 화면 2 — 배치 모드 오버레이

## 개요

플레이어가 맵 위에서 건물 위치를 직접 잡는 동안 표시되는 소형 UI.  
**전체 팝업이 아닙니다.** 화면 하단 중앙에 고정되며, 맵 뷰를 최대한 가리지 않아야 합니다.

---

## 규격

| 항목 | 값 |
|------|----|
| 위치 | 화면 하단 중앙 고정 |
| 크기 | 폭 560px 이내, 높이 160px 이내 (가능하면 더 작게) |
| 배경 | 반투명 다크 패널 (opacity 85% 내외) |
| 분위기 | 건물 관리 패널보다 미니멀. 텍스트와 버튼 위주. |

---

## 구성 요소

```
┌──────────────────────── 배치 모드 오버레이 ────────────────────────┐
│                                                                    │
│   [건물 아이콘 48×48]   Wood Floor          1 × 1 그리드           │
│                                                                    │
│   [상태 표시: ● 배치 가능] or [● 배치 불가 — 공간 부족]             │
│                                                                    │
│              [취소]              [배치 확정]                        │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

| 요소 | 설명 |
|------|------|
| 건물 아이콘 | 소형 (48×48) |
| 건물 이름 | 텍스트 |
| 그리드 크기 | `1 × 1` 형태 |
| 상태 표시 | 녹색 점 + "배치 가능" / 빨간 점 + "배치 불가 — [이유]" |
| `취소` 버튼 | 보조 버튼 (어두운 계열), 클릭 시 배치 대기 목록으로 복귀 |
| `배치 확정` 버튼 | 주 버튼 (녹색), 배치 불가 상태에서는 비활성 처리 |

---

## 상태

| 상태 | 상태 표시 | 배치 확정 버튼 |
|------|-----------|---------------|
| 배치 가능 | 녹색 점 + "배치 가능" | 활성 (녹색) |
| 범위 밖 / 겹침 | 빨간 점 + "배치 불가" | 비활성 (회색) |

## 주의사항 — 배치 모드 오버레이

1. **이 화면은 팝업이 아닙니다.** UIManager의 Open/Close 스택과 무관하게 동작하는 별도 오버레이로 구현 예정. 디자인도 팝업 크롬(타이틀바·푸터)을 달지 말아주세요.
2. **맵을 최대한 가려서는 안 됩니다.** 화면 하단에 붙여서 플레이어가 건물 미리보기(고스트)를 볼 수 있어야 합니다.
3. **건물 고스트(Ghost Preview)의 색상 피드백(녹색/빨간색)은 3D 씬에서 처리합니다.** 오버레이의 상태 표시는 그것을 텍스트로 보조하는 역할입니다.
4. **`배치 확정` 버튼은 활성/비활성 2종만 필요합니다.** hover 등 추가 상태는 선택사항.
5. **반투명 처리가 핵심입니다.** 배경이 완전히 불투명하면 맵이 안 보이므로, 배경 opacity를 80~90% 수준으로 설계해주세요.
