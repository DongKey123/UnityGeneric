**화면 이름**: InventoryPanel

## 섹션별 상세 명세

### 1. 헤더

- 좌상단: X 버튼 (닫기)
- 우상단: 무게 표시 `현재무게 / 최대무게 kg` — 무게가 80% 이상이면 색상 경고 (주황), 초과 직전이면 빨강
- 우상단 두 번째 줄: 슬롯 수 `사용슬롯 / 최대슬롯`
- 배경: 반투명 어두운 패널 (alpha 0.85 수준의 진한 회색-갈색)

---

### 2. 장비 슬롯 패널

**슬롯 구성 (6개)**:

| 슬롯 | 위치(예시) | 아이콘 힌트 |
|------|------------|-------------|
| Weapon | 좌상단 | 칼/무기 실루엣 |
| Tool | 우상단 | 도끼/곡괭이 실루엣 |
| Head | 가운데 상단 | 헬멧 실루엣 |
| Chest | 가운데 | 갑옷 실루엣 |
| Legs | 가운데 하단 | 바지 실루엣 |
| Boots | 하단 | 부츠 실루엣 |

**레이아웃**: 캐릭터 실루엣(회색 인체 도형) 주위에 6개 슬롯 배치 — LDOE 스타일

**슬롯 상태**:
- 비어 있음: 어두운 회색 배경 + 슬롯 타입 아이콘 (반투명 흰색 실루엣)
- 장착됨: 아이템 아이콘 표시 + 하단 내구도 바 (작은 녹색/주황/빨강 바)

---

### 3. 아이템 상세 패널

선택한 아이템이 없을 때: 빈 패널 또는 안내 텍스트 ("아이템을 선택하세요")

선택했을 때 표시 항목:
- 아이템 아이콘 (큰 이미지)
- 아이템 이름 (bold, 흰색)
- 카테고리 태그: `자원` / `소비` / `장비` / `특수` (색상 코딩)
- 설명 텍스트 (회색, 작은 글씨)
- 무게: `⚖ 0.5 kg`
- **[장비 전용]** 내구도: `🛡 75 / 100`
- **[장비 전용]** 티어: `★ Tier 2`
- **[장비 전용]** 슬롯 타입: `Weapon` / `Head` 등

---

### 4. 아이템 그리드

- **열 수**: 4열 고정
- **슬롯 크기**: 약 180×180 px (Cell Size 기준)
- **간격**: 15px
- **패딩**: 상하좌우 20px
- **최대 슬롯**: 20칸 (빈 슬롯도 회색 빈 칸으로 표시)

**슬롯 상태 3가지**:

| 상태 | 시각 표현 |
|------|-----------|
| 일반 | 어두운 배경 + 아이템 아이콘 + 우하단 수량 텍스트 |
| 선택됨 | 테두리 강조 (밝은 노란색 또는 흰색 glow) + 살짝 밝은 배경 |
| 장착됨 | 아이콘 위에 반투명 오버레이 + 우상단 작은 배지 (방패 또는 체크 아이콘, 초록색) |

- 수량은 스택 가능 아이템만 표시 (예: `×5`)
- 빈 슬롯은 점선 테두리 또는 흐릿한 빈 박스

---

### 5. 액션 버튼

아이템 선택 시 활성화. 선택 전에는 비활성(회색).

| 버튼 | 표시 조건 | 동작 |
|------|-----------|------|
| 사용 | 카테고리 == Consumable | 소비 아이템 사용 |
| 장착 | 카테고리 == Equipment && 미장착 | 해당 슬롯에 장착 |
| 해제 | 카테고리 == Equipment && 장착중 | 장착 해제 |
| 버리기 | 항상 표시 | 아이템 드롭 |

- 버튼 스타일: 군용 느낌의 각진 버튼, 텍스처 있는 어두운 배경
- 버리기는 빨간색 계열로 구분

## 출력 요청

1. **전체 화면 목업** (세로 모바일 기준)
2. **슬롯 상태 3종 클로즈업** (일반 / 선택 / 장착)
3. **장비 슬롯 패널 클로즈업** (6슬롯 + 캐릭터 실루엣)
4. **액션 버튼 영역 클로즈업** (활성/비활성 상태 모두)
