# 크래프팅 UI 디자인 요청서

> 시안 파일: `Game_Survival_Docs/Reference/crafting_mockup.html`

---

## 전체 패널 규격

| 항목 | 값 |
|------|----|
| 기준 해상도 | 1920 × 1080 (가로) |
| 패널 크기 | 1200 × 700 (중앙 배치) |
| 분위기 | 다크 서바이벌 — 인벤토리 패널과 동일 톤 |

---

## 구성 요소

### 1. 탭 바 (상단, 높이 44px)

| 요소 | 설명 |
|------|------|
| `tab_building` | 빌딩 탭 (비활성 / 활성 2종) |
| `tab_crafting` | 아이템 제작 탭 (비활성 / 활성 2종) |
| `btn_close` | 우측 X 닫기 버튼 |
| `tab_divider` | 탭 구분선 |

활성 탭은 하단에 골드 언더라인 강조.

---

### 2. 레시피 목록 패널 (좌측, 폭 340px)

| 요소 | 설명 |
|------|------|
| `panel_list_bg` | 목록 패널 배경 |
| `recipe_card_normal` | 레시피 카드 — 기본 상태 |
| `recipe_card_selected` | 레시피 카드 — 선택됨 (골드 테두리 glow) |
| `recipe_card_disabled` | 레시피 카드 — 재료 부족 (dim 처리) |

**카드 내부 구성 (카드 높이 약 62px):**
- 아이템 아이콘 슬롯 (44×44, 좌측)
- 아이템 이름 텍스트 영역
- 재료 수량 텍스트 영역 (초록 = 충족 / 빨강 = 부족)
- 우측 화살표 (▶)

---

### 3. 상세 패널 (우측, 나머지 폭)

| 요소 | 설명 |
|------|------|
| `panel_detail_bg` | 상세 패널 배경 |
| `detail_item_icon_frame` | 결과 아이템 아이콘 슬롯 (64×64) |
| `tag_equipment` | 카테고리 태그 — 장비 |
| `tag_resource` | 카테고리 태그 — 자원 |
| `tag_consumable` | 카테고리 태그 — 소모품 |
| `ing_row_bg` | 재료 행 배경 |
| `ing_bar_bg` | 재료 보유량 바 배경 |
| `ing_bar_fill_ok` | 재료 바 채우기 — 충족 (초록) |
| `ing_bar_fill_ng` | 재료 바 채우기 — 부족 (빨강) |

---

### 4. 하단 버튼 영역

| 요소 | 상태 | 설명 |
|------|------|------|
| `btn_craft` | normal / hover / disabled | 제작 버튼 (초록 계열) |
| `btn_cancel` | normal / hover | 취소 버튼 (어두운 골드 계열) |

`btn_craft` disabled 상태는 회색 처리, 텍스트 "재료 부족".

---

### 5. 공통 / 기타

| 요소 | 설명 |
|------|------|
| `panel_empty_hint` | 레시피 미선택 시 우측 힌트 텍스트 배경 (선택사항) |
| `col_divider` | 목록/상세 패널 구분선 |
| `row_divider` | 섹션 구분 얇은 선 |

---

## 상태별 화면

| 상태 | 설명 |
|------|------|
| A — 미선택 | 레시피 목록만, 우측은 "레시피를 선택하세요" |
| B — 제작 가능 | 선택된 카드 골드 glow, 우측 상세 + 초록 제작 버튼 |
| C — 재료 부족 | 선택된 카드에 빨강 재료 표시, 제작 버튼 disabled |

## 참고

- 전체 배경 색상: `#0d0b07` (인벤토리와 동일)
- 강조 색상: `#c8a84a` (골드)
- 충족 색상: `#5a9830` (초록)
- 부족 색상: `#a03020` (빨강)
- 비활성 투명도: 45%
- 시안 HTML 파일에서 레이아웃 및 색상 직접 확인 가능
