# 맵 / 지역 구조 설계

> DESIGN.md 1번 항목(맵/이동)의 상세 설계 문서입니다.

---

## 씬 구조

| 씬 | 역할 | 비고 |
|----|------|------|
| **MainScene** | 메인 플레이 씬 (단일) | 내 영역 + 탐험 영역 공존 |
| **EventScene_\*** | 이벤트 전용 씬 | 특수 이벤트 발생 시 전환, 완료 후 MainScene 복귀 |

- 일반 플레이(탐험·채집·건설)는 모두 MainScene 한 씬 안에서 진행한다.
- 이벤트 씬은 독립 씬으로 분리하며, 종류와 진입 조건은 추후 확정한다.

---

## 영역 시스템 (Territory)

### 개념

플레이어는 게임 시작 시 소규모 안전 구역을 보유한다.  
자원을 소비해 인접 구역을 점령하는 방식으로 영역을 단계적으로 확장한다.

```
[탐험 영역] [탐험 영역] [탐험 영역]
[탐험 영역] [내  영역] [탐험 영역]
[탐험 영역] [탐험 영역] [탐험 영역]
              ↓ 확장
[탐험 영역] [내  영역] [내  영역]
[내  영역 ] [내  영역] [탐험 영역]
[탐험 영역] [탐험 영역] [탐험 영역]
```

### 내 영역 (Safe Zone) 규칙

| 항목 | 내용 |
|------|------|
| 몬스터 스폰 | **없음** |
| 건물 설치 | **가능** |
| 자원 오브젝트 | 없음 (탐험 영역에서만 자원 채집) |
| 초기 크기 | **미정** |

### 영역 확장

| 항목 | 내용 |
|------|------|
| 방식 | 인접 구역 선택 → 자원 소비 → 점령 |
| 확장 비용 | **미정** (자원 종류, 수량) |
| 확장 단위 | **미정** (그리드 타일 단위 or 반경 단위) |
| 확장 제한 | **없음** — 무한 확장 가능 |

## 탐험 영역 (Exploration Zone)

내 영역 바깥 전체가 탐험 영역이다.

| 항목 | 내용 |
|------|------|
| 몬스터 스폰 | **있음** — SpawnTable 기반 |
| 자원 오토 스폰 | **있음** — ResourceSpawnTable 기반 |
| 건물 설치 | **불가** |
| 세부 지역 구분 | **미정** (난이도별 구역 분리 여부 추후 결정) |

---

## 자원 오토 스폰 (Resource Auto-Spawn)

탐험 영역 내 자원 오브젝트(나무, 돌 등)는 테이블 설정에 따라 자동으로 스폰·리스폰된다.

### ResourceSpawnTable (JSON)

```json
[
  {
    "resource_id": 1,
    "prefab_path": "Prefabs/Resource/Resource_Tree",
    "max_count": 30,
    "respawn_time": 120
  },
  {
    "resource_id": 2,
    "prefab_path": "Prefabs/Resource/Resource_Rock",
    "max_count": 20,
    "respawn_time": 180
  }
]
```

| 필드 | 설명 |
|------|------|
| `max_count` | 탐험 영역 내 동시에 존재하는 최대 개수 |
| `respawn_time` | 채집 후 리스폰까지 대기 시간 (초) |

- 현재 `ResourceSpawner`의 1회성 스폰을 이 테이블 기반 오토 스폰으로 교체 예정.

## 이벤트 씬

| 항목 | 내용 |
|------|------|
| 진입 방식 | 이벤트 발생 → LoadScene으로 전환 |
| 복귀 방식 | 이벤트 완료 or 탈출 → MainScene 복귀 |
| 씬 종류 | **미정** |
| 진입 조건 | **미정** (열쇠 아이템, 특정 건물 등) |

## 미결 사항

- [ ] 내 영역 초기 크기 및 확장 단위 (그리드 타일 크기)
- [ ] 영역 확장 비용 (자원 종류 + 수량)
- [ ] 영역 최대 크기 제한 or 확장 조건
- [ ] 탐험 영역 세부 구분 (난이도별 구역 분리 여부)
- [x] 전체 맵 크기 — **무한 확장** (상한 없음)
- [ ] 이벤트 씬 종류 및 진입 조건
