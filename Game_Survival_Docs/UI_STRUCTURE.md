> 참고 레퍼런스: Last Day on Earth: Survival

## 3. 요소별 상세 설명

### 3-1. 좌상단

#### 미니맵
- 크기: 약 150×150px 원형 마스크
- 표시 내용: 플레이어 위치(흰 점), 주변 자원(녹색), 적(빨간 점), 건물(회색)
- 구현 시점: 1차 껍데기(빈 원형 패널) → 맵 시스템 완성 후 렌더텍스처 연동
- 탭 시: 월드맵 패널 열기 (추후 연동)

#### 지역명
- 미니맵 하단에 텍스트로 표시
- 예) `베이스 캠프`, `숲 지역 A`
- 씬/지역 진입 시 SurvivalEntry에서 주입

---

### 3-2. 상단 중앙

#### 낮/밤 시계
- 원형 시계 아이콘 또는 태양/달 아이콘 + 진행 바
- 게임 내 하루 사이클(예: 실시간 10분 = 게임 1일) 표시
- 낮(주황), 밤(남색)으로 색상 구분
- 구현 시점: 낮/밤 시스템 설계 후

---

### 3-3. 우상단

#### 재화 표시
- 골드(기본 화폐): 아이콘 + 숫자, 항상 표시
- 프리미엄 화폐(💎): 아이콘 + 숫자, 항상 표시
- 재화 변동 시 숫자 카운팅 애니메이션 적용 권장

#### 우편 버튼
- 빨간 점(Red Dot) 알림 표시 — 미수령 우편 존재 시
- 탭 시: 우편 패널 열기 (추후 구현)

#### 상점 버튼
- 탭 시: 상점 패널 열기 (추후 구현)
- 할인/이벤트 중 뱃지 표시 가능

#### 설정 버튼
- 탭 시: 설정 패널 열기 (BGM/SFX 볼륨, 진동, 언어 등)
- 게임 일시정지 처리 포함

---

### 3-4. 하단 좌

#### 가상 조이스틱
- 기존 VirtualJoystick 그대로 유지
- 좌하단 고정, 터치 시 팔로우 방식

---

### 3-5. 하단 중앙

#### 퀵슬롯 (3칸)
- 슬롯 구성: 무기 / 도구 / 소모품
- 각 슬롯: 아이템 아이콘 + 내구도 바(하단) + 수량(우하단)
- 슬롯 탭 시: 해당 아이템 장착/사용
- 장착된 슬롯: 테두리 강조(흰색 또는 노란색)
- 구현 시점: UI 껍데기 먼저, 장비 시스템 완성 후 연동

#### 무게 표시
- 퀵슬롯 하단에 텍스트로 표시
- 형식: `🎒 12 / 50 kg`
- 90% 이상: 주황색, 100%: 빨간색으로 강조
- Inventory.OnChanged 이벤트 구독으로 실시간 갱신

---

### 3-6. 하단 우

#### 채집 버튼 (컨텍스트)
- 자원 범위 진입 시만 활성화
- 기존 로직 유지

#### 공격 버튼 (컨텍스트)
- 적이 공격 범위 진입 시만 활성화
- 기존 로직 유지

#### 인벤토리 버튼
- 탭 시: 인벤토리 패널 열기/닫기 토글

#### 크래프트 버튼
- 탭 시: 크래프팅 패널 열기

#### 빌딩 버튼
- 탭 시: 빌딩 모드 패널 열기

#### 월드맵 버튼
- 탭 시: 월드맵 패널 열기 (지역 이동)
- 구현 시점: 맵 시스템 완성 후

## 4. 월드 스페이스 HUD (별도 구현)

| 요소 | 대상 | 표시 조건 |
|---|---|---|
| HP 바 | 플레이어 | 항상 표시 or 피격 시만 (미정) |
| 스태미나 바 | 플레이어 | 스태미나 소모 시만 |
| HP 바 | 적 | 피격 시만 표시, N초 후 자동 숨김 |

- Canvas: World Space, 캐릭터 루트의 자식으로 배치
- 카메라를 향해 항상 빌보드(LookAt) 처리

## 6. 구현 순서 (권장)

1. **MainPanel 레이아웃 재배치** — 가로형 기준으로 기존 버튼 위치 정리
2. **재화 표시** — 골드/프리미엄 UI + 더미 데이터 연결
3. **퀵슬롯** — UI 껍데기 3칸, 장비 시스템 전까지 빈 슬롯
4. **무게 표시** — Inventory.OnChanged 연동
5. **미니맵** — 빈 원형 패널 배치 (렌더텍스처는 추후)
6. **지역명 표시** — SurvivalEntry에서 텍스트 주입
7. **낮/밤 시계** — 낮/밤 시스템 구현 병행
8. **우편/상점/설정 버튼** — 버튼만, 패널은 추후
