# 플레이어 상세 설계

> DESIGN.md 2번 항목(플레이어)의 상세 설계 문서입니다.

---

## 성장 구조

레벨과 스탯 성장은 완전히 독립적인 두 축으로 운영한다.

| 축 | 역할 | 비고 |
|----|------|------|
| **레벨** | 콘텐츠 해금 조건 | 스탯에 직접 영향 없음 |
| **장비** | 스탯 부여 | 레벨과 무관하게 장비로만 스탯 결정 |

---

## 레벨 시스템

### 경험치 획득

| 행동 | 획득 여부 |
|------|-----------|
| 몬스터 처치 | ✅ |
| 자원 채집 | ✅ |
| 건물 건설 | ✅ |
| 크래프팅 | ✅ |
| 획득량 세부 수치 | **미정** |

### 레벨의 역할 (해금 조건)

| 조건 적용 대상 | 내용 |
|---------------|------|
| 크래프팅 레시피 | 특정 레벨 이상 레시피 해금 |
| 건물 블루프린트 | 특정 레벨 이상 건물 건설 가능 |
| 탐험 지역 | 지역별 입장 권장 레벨 (강제 제한 여부 **미정**) |
| 장비 장착 | 장비별 레벨 요구치 (도입 여부 **미정**) |

- 레벨 상한: **미정**
- 레벨업 연출 / 알림 방식: **미정**

---

## 기본 스탯

플레이어 고유 기본값. 장비 없이도 존재하며, 장비 장착 시 추가 수치가 합산된다.

| 스탯 | 기본값 | 장비 증가 여부 | 비고 |
|------|--------|---------------|------|
| **HP** | **미정** | ✅ | 0 되면 사망 |
| **스태미나** | **미정** | ✅ | 달리기·공격 소모, 시간 회복 |
| **이동 속도** | **미정** | ✅ | 기본 이동 기준 |
| **인벤토리 무게 한도** | **미정** | ✅ | 장비(배낭류)로 증가 |

> 기본 공격력 / 방어력은 **없음** — 장비 없이 맨손 공격력은 별도 고정값으로 처리 예정.

---

## 장비 스탯

장비 장착 시 플레이어 스탯에 합산되는 수치.

| 스탯 | 적용 장비 슬롯 | 비고 |
|------|--------------|------|
| **공격력** | 무기 (Weapon) | 미장착 시 맨손 고정값 |
| **방어력** | 방어구 (Head / Chest / Legs / Boots) | 합산 |
| **HP 보너스** | 방어구 전반 | 기본 HP에 합산 |
| **스태미나 보너스** | **미정** | |
| **이동 속도 보너스** | **미정** | |
| **채집 효율** | 도구 (Tool) | 1회 채집량 or 채집 속도 증가 |
| **인벤토리 무게 한도 보너스** | 도구 (배낭류 별도 검토) | |

### 장비 슬롯 구성

| 슬롯 | 종류 |
|------|------|
| Weapon | 무기 |
| Tool | 도구 (채집용) |
| Head | 머리 방어구 |
| Chest | 상체 방어구 |
| Legs | 하체 방어구 |
| Boots | 신발 |

---

## HP 시스템

| 항목 | 내용 |
|------|------|
| 자연 회복 | **없음** — 아이템 사용으로만 회복 |
| 회복 아이템 | 붕대, 음식 등 소모성 아이템 |
| 최대 HP | 기본값 + 장비 HP 보너스 합산 |

---

## 스태미나 시스템

| 항목 | 내용 |
|------|------|
| 소모 조건 | 달리기, 공격 |
| 회복 방식 | 시간 자연 회복 |
| 회복 속도 | **미정** |
| 스태미나 0 도달 시 | 달리기 불가 / 공격 속도 감소 (세부 **미정**) |

---

## 사망 처리

| 항목 | 내용 |
|------|------|
| 사망 조건 | HP = 0 |
| 인벤토리 드롭 | 보유 아이템 일부 드롭 (비율 **미정**) |
| 장비 드롭 | **미정** (장비 포함 여부) |
| 부활 위치 | 베이스 복귀 |
| 드롭 아이템 유지 시간 | **미정** (회수 가능 시간) |
